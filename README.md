# SummitHack-2026-Frontend

Static frontend prototype for a load-shifting energy website.

## Pages

- `index.html` - Home and navigation.
- `about.html` - Team mission and project summary.
- `emissions.html` - Average-vs-user carbon emissions and monthly cost estimator.
- `heatmap.html` - Area-based renewable energy heat map.
- `impacts.html` - Carbon emissions and public health implications.

## Run locally

Open `index.html` directly in your browser, or serve the folder with:

```bash
python3 -m http.server 8000
```
